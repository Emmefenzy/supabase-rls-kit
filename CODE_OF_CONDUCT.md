# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful and harassment-free community. Be considerate, assume good faith, accept constructive feedback, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing and publishing private information without consent.

Project maintainers may remove comments, commits, issues or contributions that violate this code. For concerns, contact the repository maintainer privately.
